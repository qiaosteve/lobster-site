🤖 AI对话助手

ChatGPT (OpenAI)

⭐⭐⭐⭐⭐ 通用最强

依然是目前综合能力最强的。写作、编程、分析都不错。GPT-4o免费版够用，Plus版更快更稳。

适合：日常使用、写作、简单编程

缺点：国内需要魔法，Plus涨价了

Claude (Anthropic)

⭐⭐⭐⭐⭐ 长文本之王

200K上下文，处理长文档首选。写作更自然，代码质量高。最近有免费额度了。

适合：长文档分析、论文阅读、高质量写作

缺点：国内需要魔法，偶尔比较啰嗦

DeepSeek

⭐⭐⭐⭐⭐ 国产之光

国产AI天花板，编程能力极强，价格便宜。API调用性价比最高。

适合：编程、API调用、数据分析

缺点：偶尔服务器繁忙

Kimi (月之暗面)

⭐⭐⭐⭐ 国产长文本

200万字上下文，免费，中文支持好。搜索联网功能实用。

适合：长文档处理、资料整理、中文写作

缺点：复杂推理稍弱

🎨 AI绘图工具

Midjourney

⭐⭐⭐⭐⭐ 艺术感最强

生成图片最有艺术感，审美在线。V6之后写实能力也强了。

适合：插画、概念图、海报

缺点：需要Discord，按月收费

Stable Diffusion

⭐⭐⭐⭐ 最灵活

开源免费，本地部署，完全控制。ControlNet、LoRA生态强大。

适合：需要精细控制、批量生成、隐私需求

缺点：学习曲线陡，需要好显卡

DALL-E 3

⭐⭐⭐⭐ 最听话

理解能力最强，你说啥它画啥。ChatGPT里直接用。

适合：需要精确还原描述的场景

缺点：艺术感不如MJ，有内容限制

📝 AI写作工具

Notion AI

⭐⭐⭐⭐ 笔记首选

在笔记里直接用AI，整理、总结、扩展都很方便。和Notion深度集成。

适合：知识管理、笔记整理、团队协作

Jasper

⭐⭐⭐⭐ 营销文案

专门为营销设计的，有各种文案模板。英文内容首选。

适合：广告文案、邮件营销、社媒内容

缺点：贵，对中文支持一般

💻 AI编程工具

GitHub Copilot

⭐⭐⭐⭐⭐ 编程必备

代码补全最智能，和各种IDE集成好。一个月能省不少时间。

适合：日常编程

价格：个人版 $10/月

Cursor

⭐⭐⭐⭐⭐ AI优先的编辑器

基于VS Code，AI功能更强。可以直接和AI结对编程。

适合：全栈开发、重构、新项目

价格：免费版够用，Pro版 $20/月

Claude Code

⭐⭐⭐⭐⭐ 终端AI

在终端里直接让AI帮你写代码、调试、重构。配合Claude模型，能力强。

适合：终端党、自动化脚本、服务器开发

🎬 AI视频/音频

Runway

⭐⭐⭐⭐ 视频生成

Gen-2之后效果好了很多，文字/图片生成视频都可以。

适合：短视频、广告素材、创意视频

ElevenLabs

⭐⭐⭐⭐⭐ 最强TTS

语音合成效果最好，支持克隆声音。中文效果也不错。

适合：有声书、配音、播客
